# Vertex+ (HyP3+) Brand Assets

This directory contains brand-specific assets for the Vertex+ deployment (vertex-plus.asf.alaska.edu).

## Required Assets

### Logo Files
- `logo.svg` - Main application logo with "+" branding (SVG format)
- `logo-white.svg` - White version for dark backgrounds (optional)
- `logo.png` - Fallback PNG version (optional)

### Favicon
- `favicon.ico` - Browser favicon with distinctive color (16x16, 32x32, 48x48)
- `favicon-16x16.png` - 16x16 PNG
- `favicon-32x32.png` - 32x32 PNG
- `apple-touch-icon.png` - 180x180 for iOS (optional)

### Additional Brand Assets (Optional)
- `og-image.png` - Open Graph image for social sharing (1200x630)
- `hero-banner.jpg` - Hero section background image
- `pattern.svg` - Brand pattern/texture
- `splash-icon.png` - PWA splash screen icon
- `plus-badge.svg` - Special "+" badge overlay

## Current Assets

Currently using placeholder assets. To add brand assets:
1. Create distinctive Vertex+ logo (consider adding "+" to existing logo)
2. Use teal/cyan color scheme (#00796b) instead of blue
3. Update references in `src/styles/brands/vertex-plus.scss`
4. Update `angular.json` file replacements

## Asset Guidelines

- **Colors**: Primary Teal (#00796b), Accent Amber (#ffa726)
- **Differentiation**: Logo should be clearly distinct from standard Vertex
- **Plus Branding**: Incorporate "+" symbol in logo or as badge
- **File Formats**: Prefer SVG for logos, PNG for favicons
- **Sizes**: Ensure logos work at multiple sizes (min 24px height)
- **Transparency**: Use transparent backgrounds where appropriate

## Design Notes

Vertex+ uses a teal/cyan color palette to distinguish it from standard Vertex's blue theme. This creates clear visual differentiation while maintaining professional branding.

Consider these design elements for Vertex+:
- Slightly more modern/premium feel
- "Plus" badge or icon treatment
- Amber/orange accent for highlights
- Consistent with ASF brand guidelines
